## 背景

在 SESSION-002 的 C/S 架构基础上，**进一步细化世界模拟机制**。需要解决：
1. 世界事件如何产生大事件
2. 多个角色如何基于位置感知同一事件
3. **地图状态（固化）vs 角色记忆（主观）** 的明确区分
4. 剧情如何涌现而非脚本化

---

## 核心设计决策

### 1. 跨场景感知：简化距离模型

- 事件定义 **sound / light / damage / vibration** 四个传播通道
- 每个通道有：传播半径 + 障碍物削减
- 感知判定：damage > light（直线视距）> sound（距离+障碍）> vibration（穿透）
- 距离超出所有通道 → 完全无感知

**示例：** 城堡外爆炸
- 地下室角色：distance 4 房间，多层楼板 → 无视、听不清、**感到震动**
- 城堡外角色：distance 0 → **满伤害 + 火焰 + 光亮 + 巨响**

### 2. 地图状态 vs 角色记忆

**严格隔离**，建立两个独立子系统：

| 系统 | 性质 | 谁可读 | 谁可写 | 生命周期 |
|---|---|---|---|---|
| **Map State** | 客观真相，固化 | 全员按可见性 | 服务端 | 永久 |
| **Memory** | 主观认知 | 仅本人 | 仅本人 | 衰减/可重置 |

**关键规则：**
- 角色**身处场景**时看到的是**当前 Map State**（不是记忆）
- 角色**主动回忆**时显示记忆中的过去状态
- 两者**可能不一致**（NPC 修好破门后，角色记忆里"门是破的"）
- LLM 叙事器结合两者生成："破败的城堡大门。墙上有明显烧焦痕迹。你记得三周前这里发生过一场大火。"

### 3. StateChange 状态变更记录

每次 Map State 变化都记录**完整历史**：
- before/after 快照
- 变更原因（事件/天气/老化/玩家动作）
- witnessedBy：哪些角色目睹了这次变更
- 作为记忆锚点：角色记忆引用具体的 StateChangeId

### 4. 事件生成：混合但优先涌现

| 维度 | 决定 |
|---|---|
| 世界观 | 设计师定义（地理/势力/历史/初始NPC/初始关系） |
| 关键节点 | **无**（无脚本剧情） |
| 大事件 | 由 NPC 行为 + 玩家动作 + 世界状态**涌现** |
| 设计师角色 | 提供土壤，不写剧本 |

**World Weaver（世界织网者）**：
- 特殊的"观察型"AI Agent
- 不直接干预世界
- 分析世界状态，检测潜在戏剧张力
- 偶尔建议微妙的"催化条件"（spawn 新 NPC、生成物品线索、改变天气）
- 永远不强制结果

**大事件涌现路径示例：**
```
玩家进入某区域 → NPC "警觉" → 接近玩家 → 互动（对话/交易/冲突）
→ 冲突升级战斗 → 战斗产生爆炸事件 → 火灾蔓延
→ 第三方 NPC 介入（逃跑/反击/求援）→ 求援引发更大冲突
```

### 5. 地图状态演化：全背景模拟

每个 World Tick 中持续模拟：

| 系统 | 行为 |
|---|---|
| 时间推进 | 时间/季节/光照 |
| 天气演化 | 天气自身变化 + 影响所有场景（灭火/积水/风化） |
| 火灾蔓延 | 燃烧房间向相邻蔓延；燃料耗尽熄灭 |
| 结构老化 | 已损坏结构持续恶化，完整度=0 坍塌 |
| 植被生长 | 野外场景随季节变化 |
| 尸体/物品腐烂 | 时间敏感的降解 |
| 疾病传播 | 感染在 NPC 间扩散 |
| NPC 自发行为 | 每个 NPC Agent 自主决策 |
| 知识衰减 | per-character relevance 递减 |
| 世界织网者 | 涌现式剧情催化 |

## 关键数据结构

### RoomState（地图状态）
- `base`：静态（名称、描述、出口、材质、容量）
- `dynamic`：动态（结构完整度、火灾、天气、时辰、季节、可见物体、隐藏物体）
- `history`：StateChange 数组

### MemoryEntry（角色记忆）
- 锚定到 `StateChangeId` 或 `WorldEventId`
- 包含 `mapStateReference` 引用 + `captured` 快照
- 衰减元数据（relevance, permanent, reinforcedAt）

### WorldEvent
- 基础字段（id, type, tick, worldTime, location, payload, visibility）
- **propagation**：四个通道的传播参数（sound, light, damage, vibration）
